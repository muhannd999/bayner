# باينر (Bayner) — مساعد التاجرة الذكي لمشاريع الكيك والحلويات

نظام تشغيل متكامل (Next.js App Router + TypeScript + Tailwind CSS) مصمم خصيصاً لمشاريع الكيك والحلويات والأسر المنتجة في السعودية والخليج.

## المميزات الأساسية (7 مسارات متكاملة)

1. **لوحة التحكم والأرباح (`/`)**: مؤشرات المبيعات، التكلفة والهدر، صافي الربح، العربون المعلق، وترتيب ربحية الوصفات.
2. **المخزن وحاسبة التسعير (`/pantry`)**: مكتبة المقادير والتغليف مع تعديل فوري للأسعار، وحاسبة تفاعلية للهدر وساعات العمل والتشغيل وعمولات المنصات.
3. **استوديو المنيو (`/menu-studio`)**: إدارة الأصناف المنشورة، إعدادات الكيك المخصص، وتوليد صورة منيو جاهزة للستوري بصيغة `PNG`.
4. **الطلبات، التقويم، وقائمة المشتريات (`/orders`)**: إدارة الطلبات، قفل/فتح أيام الحجز، فواتير `PDF` بالعربون، وقائمة مشتريات مجمعة للطلبات النشطة.
5. **التقارير المالية والمصروفات (`/finance`)**: دفتر المصروفات والهدر الفعلي، حساب صافي الربح النقدي، وتصدير ملف `CSV / Excel` متوافق مع العربية (`UTF-8 BOM`).
6. **مركز الواتساب والرد الآلي (`/whatsapp`)**: محاكي بوت حي مرتبط ببيانات المتجر، جسر الواتساب المجاني، وإعدادات واختبار `Meta WhatsApp Cloud API` (`/api/whatsapp/webhook` و`/api/whatsapp/send`).
7. **واجهة متجر العميلة (`/store`)**: تصفح المنيو، تصميم كيكة مخصصة مع إرفاق صورة مرجعية، اختيار موعد من الأيام المفتوحة فقط، وتتبع حالة الطلب برقم الطلب.

---

## التشغيل والتطوير عبر VS Code

1. افتح المجلد في **VS Code**.
2. لتشغيل السيرفر المحلي:
   ```bash
   npm install
   npm run dev
   ```
   أو من قائمة VS Code: `Terminal` -> `Run Task...` -> `Bayner: Start Dev Server`.
3. افتح المتصفح على: `http://localhost:3000` (وصفحة العميلة على `http://localhost:3000/store`).

## النشر المجاني وربط قاعدة البيانات

* **الاستضافة المجانية:** يدعم النشر مباشرة على **Vercel** بدون تكلفة خادم.
* **قاعدة البيانات السحابية:** أنشئ مشروعاً مجانياً على **Supabase**، ثم انسخ محتوى الملف `supabase/schema.sql` في SQL Editor وأضف المفاتيح في `.env.local` استناداً إلى `.env.example`.
* **ربط واتساب الرسمي (Meta Cloud API):** أضف `WHATSAPP_VERIFY_TOKEN` و`WHATSAPP_PHONE_NUMBER_ID` و`WHATSAPP_ACCESS_TOKEN` في البيئة، وضع رابط `https://your-domain.com/api/whatsapp/webhook` في لوحة Meta Developers.
